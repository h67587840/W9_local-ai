單元一：多采多姿的植物

認識植物的多樣性，了解植物各部分與功能，以及植物如何生長與與環境互動。

📖 單元內容：植物有哪些不同？

  1. 植物的多樣性： 植物有各種大小、形狀與顏色，可以分為開花植物與不開花植物。
  2. 植物的分類（簡介）： 依照有無種子，分為「種子植物」（如玉米、向日葵）與「孢子植物」（如蕨類、蘚苔類）。
  3. 植物各部分與功能： 根（固定、吸水養分）、莖（支持、輸送）、葉（製造養分、呼吸、蒸騰）、花（生殖、結種子）、果實（保護種子、幫助散播）、種子（繁殖下一代）。
  4. 植物的生長變化： 種子 → 發芽 → 幼苗 → 生長成株 → 開花 → 結果 → 種子散播。
  5. 植物與環境： 植物需要陽光、水、空氣與適宜的溫度才能健康成長。

🎯 學習重點

  • 能說明植物有多樣的外觀，並舉例開花植物與不開花植物。
  • 知道植物可大致分為種子植物與孢子植物。
  • 說明根、莖、葉、花、果實、種子各自的功能。
  • 能依序描述植物從種子到結果的生長變化。
  • 了解植物生長需要的條件：陽光、水、空氣、適宜溫度。

🔍 解析介紹

1. 植物的分類：植物依照繁殖方式不同，可分為種子植物（透過種子繁殖，如稻米、蘋果樹）與孢子植物（透過孢子繁殖，如蕨類、蘚苔類，沒有花與種子）。

圖一：植物依照有無種子，大致分為種子植物與孢子植物。

2. 植物各部分與功能：

圖二：根、莖、葉、花、果實、種子各有不同功能。

3. 植物生長的變化：種子在適宜條件下發芽，長成幼苗，再生長成株，開花後結果，種子散播後又可長成新植株，形成生命週期。

圖三：種子 → 發芽 → 幼苗 → 成株 → 開花結果。
🌱 植物生長需要的條件： 陽光、水、空氣與適宜的溫度，缺一不可。種子發芽剛開始不需要陽光，但長出葉片後就需要陽光進行光合作用。

單元二：生活中的力

認識力的概念，了解力的效果，以及接觸力與非接觸力的差別。

📖 單元內容：力在哪裡？

  1. 什麼是力？ 力可以是「推」或「拉」，例如推門、拉抽屜、踢球。
  2. 力的效果： 力可以改變物體的運動狀態（讓靜止物體動起來，或讓運動物體變快、變慢、改變方向），也可以改變物體的形狀（擠壓橡皮擦、拉伸橡皮筋）。
  3. 接觸力與非接觸力： 接觸力需要兩物體接觸才能產生（如推、拉、摩擦力）；非接觸力不需要接觸（如磁力、重力）。
  4. 磁力： 磁鐵可以吸引鐵、鎳、鈷等金屬，異極相吸、同極相斥。
  5. 摩擦力與重力： 摩擦力會阻礙物體運動；重力讓物體向下掉落。

🎯 學習重點

  • 能說明什麼是力，並舉出推與拉的例子。
  • 說明力可以改變物體的運動狀態與形狀。
  • 區分接觸力與非接觸力，並各舉例。
  • 了解磁力的基本性質（異極相吸、同極相斥）。
  • 認識摩擦力與重力在生活中的表現。

🔍 解析介紹

1. 推與拉：力通常分為「推」與「拉」兩種方式。推開門是用力將門推離自己；拉抽屜則是將抽屜拉向自己。無論是推還是拉，都會對物體產生力。

圖四：推與拉都是力的常見表現。

2. 力的效果：改變運動與形狀：踢球可以讓靜止的球動起來（改變運動）；接住飛來的球可以讓球變慢或停止；擠壓橡皮擦會改變形狀；拉伸橡皮筋也會改變形狀。

圖五：擠壓橡皮擦，力改變了它的形狀。

3. 接觸力與非接觸力：接觸力需要兩物體「接觸」才能產生力，例如推桌子、拉繩子、摩擦力。非接觸力則不需要接觸，例如磁力吸鐵釘、地球的重力讓蘋果掉下來。

圖六：力可分為接觸力與非接觸力。
🧲 磁力小知識： 磁鐵有 N 極與 S 極兩極，異極相吸（N-S）、同極相斥（N-N、S-S）。磁力可以穿過紙張、木頭等物質傳遞。

單元三：奇妙的空氣

認識空氣的性質，了解空氣佔有空間、有重量、有壓力，以及空氣與燃燒、呼吸的關係。

📖 單元內容：空氣有什麼神奇之處？

  1. 空氣佔有空間： 空氣雖然看不見，但它佔有空間。例如在紙杯底打孔、把紙杯倒扣進水中，紙不會濕。
  2. 空氣有重量： 空氣本身有重量，兩邊平衡的天平，一邊放入充滿空氣的氣球後會偏低。
  3. 空氣的壓力： 空氣會對四周施加壓力，例如吸管喝飲料、吸盤吸住桌面。
  4. 空氣的成分（簡介）： 空氣主要包含氮氣、氧氣、二氧化碳等氣體。
  5. 空氣與燃燒、呼吸： 燃燒需要氧氣，人與動物呼吸也需要氧氣並排出二氧化碳。

🎯 學習重點

  • 能說明空氣佔有空間，並舉出實驗例子。
  • 了解空氣有重量，能進行簡單比較實驗。
  • 說明空氣會產生壓力，並舉生活例子（吸管、吸盤）。
  • 知道空氣中含有氧氣，燃燒與呼吸都需要氧氣。
  • 了解植物透過光合作用製造氧氣，與動物呼吸形成平衡。

🔍 解析介紹

1. 空氣佔有空間：空氣看不見摸不著，但它確實佔有空間。經典實驗：將一張紙塞進杯底，杯子倒扣直插入水中，杯內的空氣阻擋水進入，紙不會濕，證明空氣佔據了杯內空間。

圖七：空氣佔據杯內空間，水進不去，紙就不會濕。

2. 空氣有重量：雖然空氣很輕，但累積起來就有重量。實驗中，天平兩端平衡，將一邊的氣球充滿空氣，該邊會下降，證明空氣有重量。

3. 空氣的壓力：空氣包圍著地球，對物體施加壓力。吸管喝飲料時，吸管內空氣被吸走，外面的大氣壓力把飲料推進吸管；吸盤吸住桌面，也是利用空氣壓力差。

圖八：吸管內外空氣壓力差，使飲料被推進吸管。

4. 空氣與燃燒、呼吸：蠟燭燃燒需要氧氣，罩上玻璃杯後氧氣耗盡，蠟燭就會熄滅。人與動物呼吸也會吸入氧氣、呼出二氧化碳；植物則透過光合作用製造氧氣。

🌱 空氣循環： 動物呼吸吸入氧氣、呼出二氧化碳；植物光合作用吸收二氧化碳、釋出氧氣。兩者共同維持空氣中氧氣與二氧化碳的平衡。

單元四：廚房裡的科學

從廚房現象認識物質的狀態、狀態變化、混合與分離，以及簡單的酸鹼概念。

📖 單元內容：廚房裡有什麼科學？

  1. 固體、液體、氣體： 廚房中隨處可見三態物質，例如冰塊（固體）、水（液體）、水蒸氣（氣體）。
  2. 物質的狀態變化： 冰塊融化（固→液）、水沸騰（液→氣）、水蒸氣遇冷凝結成水滴（氣→液）。
  3. 水的冰點與沸點： 水在 0℃ 結冰，在 100℃ 沸騰。
  4. 混合與分離： 蒜頭與鹽混合可用篩選分開；鹽水可透過蒸發得到鹽；鐵屑與麵粉混合可用磁鐵分離。
  5. 酸鹼簡介： 檸檬汁、醋具有酸性；小蘇打水具有鹼性；可用紫色甘藍汁作為指示劑觀察顏色變化。

🎯 學習重點

  • 能舉出廚房中固體、液體、氣體的例子。
  • 說明常見的狀態變化（融化、沸騰、凝結）。
  • 知道水的冰點是 0℃，沸點是 100℃。
  • 舉例生活中的混合物分離方法（篩選、蒸發、磁選）。
  • 認識簡單的酸性與鹼性物質。

🔍 解析介紹

1. 三態物質與狀態變化：固體有固定形狀與體積（如冰塊、餅乾）；液體體積固定但形狀隨容器改變（如水、醬油）；氣體沒有固定形狀與體積（如水蒸氣）。加熱冰塊會融化成水；水加熱到 100℃ 會沸騰變成水蒸氣；水蒸氣遇到冷鍋蓋會凝結成小水滴。

圖九：冰塊→水→水蒸氣，以及逆向的凝結。

2. 混合與分離：廚房中常見混合物，例如鹽混在蒜頭裡，可用篩子篩選；鹽水可將水蒸發掉，留下鹽晶；鐵屑混在麵粉中，可用磁鐵把鐵屑吸出來。

圖十：篩選可分開大小不同的固體；磁選可把鐵屑吸出。

3. 酸鹼簡介：檸檬汁、醋是酸性；小蘇打水、肥皂水是鹼性。紫色甘藍汁遇酸變紅、遇鹼變綠/藍，可當作天然指示劑。

🛡️ 安全提醒： 廚房實驗請在大人陪同下進行，不要隨意嘗試不明物質，使用熱水、爐具時要特別小心，避免燙傷。
